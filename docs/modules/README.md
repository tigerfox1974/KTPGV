# KTPGV Module Documentation

Bu klasör çalışan uygulamanın modül hafızasıdır. Belgeler kodu değiştirmez; mevcut kod yollarını, iş kurallarını ve geliştirme sırasında korunması gereken davranışları açıklar.

## Kaynak önceliği
1. En yeni kullanıcı kararı / Decision Log
2. Business Rules / Project Memory
3. Bu modül belgesi
4. Mevcut kodun doğrulanmış davranışı

Bir modülde değişiklik yapılacaksa önce ilgili belge ve burada listelenen kaynak dosyalar okunmalıdır.
